글과 여백 지원

사진 위에 글을 얹어 조용한 이미지 작품을 만드는 앱, 글과 여백의 지원 안내입니다.

도움이 필요한 경우

앱 사용 중 오류, 저장 문제, 폰트 표시 문제, 프로젝트 불러오기 문제 등이 발생하면 아래 내용을 포함해 문의해 주세요.

  • 사용 기기: 예) iPhone 16, iPad Pro M4
  • iOS/iPadOS 버전
  • 앱 버전
  • 문제가 발생한 화면과 상황
  • 가능하면 스크린샷

자주 확인할 사항

  • 사진 저장이 되지 않을 경우 iOS 설정에서 사진 추가 권한을 확인해 주세요.
  • 일부 한글 입력은 iOS Simulator에서 자모가 분리되어 보일 수 있습니다. 실기기 입력 또는 복사/붙여넣기에서는 정상일 수 있습니다.
  • 폰트가 적용되지 않을 경우 앱에 포함된 폰트 파일과 라이선스 고지 상태를 확인해 주세요.

문의

지원 문의는 GitHub Issues 또는 App Store의 개발자 연락 경로를 통해 남겨 주세요.

GitHub Pages 사용 시 이 문서가 지원 URL로 사용될 수 있습니다.
