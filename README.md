# 글과 여백 App Store URL 페이지

GitHub Pages에 그대로 올려서 사용할 수 있는 HTML 파일 모음입니다.

## App Store Connect 입력 추천

- 지원 URL: `https://<github-id>.github.io/<repo>/support.html`
- 마케팅 URL: `https://<github-id>.github.io/<repo>/`
- 개인정보 처리방침 URL: `https://<github-id>.github.io/<repo>/privacy.html`
- 저작권/라이선스 안내 URL: `https://<github-id>.github.io/<repo>/copyright.html`

## 포함 파일

- `index.html` : 마케팅 URL용
- `support.html` : 지원 URL용
- `privacy.html` : 개인정보 처리방침 URL용
- `copyright.html` : 저작권 및 오픈소스/글꼴 라이선스 안내용
- `style.css` : 공통 스타일
